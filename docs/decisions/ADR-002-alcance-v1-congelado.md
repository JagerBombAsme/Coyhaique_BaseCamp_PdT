# ADR-002 — Alcance funcional V1 congelado

## Estado

Aceptado.

## Contexto

El proyecto contiene suficientes funcionalidades para completar una V1 académica y técnicamente demostrable. Agregar funciones durante la implementación aumenta el riesgo de scope creep y compromete pruebas y cierre.

## Decisión

No se incorporarán nuevas funcionalidades a V1.

Las nuevas ideas se registrarán como trabajo futuro.

Las referencias de diseño no generan automáticamente requerimientos.

## Consecuencias

- El backlog funcional queda congelado.
- Se permiten correcciones, descomposición de historias y tareas técnicas necesarias.
- No se permiten nuevas capacidades de producto sin reabrir formalmente el alcance.
