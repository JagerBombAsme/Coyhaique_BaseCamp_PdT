# Evidencias

Esta carpeta almacena evidencia técnica y académica del proyecto.

Ejemplos:

- capturas de pantallas implementadas;
- resultados de pruebas;
- capturas de pruebas en dispositivo;
- evidencias de builds;
- resultados de `flutter analyze`;
- resultados de tests;
- evidencias de despliegue web;
- evidencias de Google Play Internal Testing;
- capturas del panel administrativo;
- evidencias de RLS y control de acceso;
- documentos de validación.

## Convención sugerida

```text
evidence/
├── HU-01/
├── HU-02/
├── HU-03/
├── HU-05/
├── ...
├── deployment/
└── qa/
```

No almacenar secretos, credenciales, tokens ni archivos `.env` en esta carpeta.
